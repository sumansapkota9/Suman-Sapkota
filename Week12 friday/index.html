Five rules to keep

  1. An effect runs after the screen paints. Rendering comes first, then the effect.
  2. Empty brackets mean once. A value in brackets means on change.
  3. List every value the effect reads. A missing value reads old data.
  4. Return a cleanup for timers and subscriptions. Stopping matters as much as starting.
  5. Start the fetch inside the effect. Loading, error, and abort live there.
