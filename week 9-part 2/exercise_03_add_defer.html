Defer in Action

A normal <head> script runs before the page exists, so it cannot find the elements below it. A deferred script waits until the page is fully parsed — then runs, in order.

Live result

Before — scripts block the page

<head>
  <script src="app.js"></script> <!-- blocks parsing -->
  <script src="analytics.js"></script> <!-- blocks parsing -->
</head>

After — scripts wait their turn

<head>
  <script src="app.js" defer></script> <!-- runs after parsing, in order -->
  <script src="analytics.js" async></script> <!-- runs whenever it arrives -->
</head>
