Fixes Demo form

Fixes applied on this page

  • Skip link at the top, so keyboard users can jump past navigation.
  • Semantic landmarks: <header>, <nav>, <main>, <section>, <footer>.
  • Every input has a real <label> — no placeholder-only fields.
  • Dark text (#0D1633) on a light background for strong colour contrast.
  • Visible focus outline (gold) on links, buttons, and inputs.
  • Page language set: lang="en", and a descriptive page title.
  • Buttons are real <button> elements, not divs.

How to check: open this page in Chrome → right-click → Inspect → Lighthouse tab → Accessibility → Generate report.
