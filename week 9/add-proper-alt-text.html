🖼️ Add Proper Alt Text

Alt text tells screen-reader users what an image shows. Good alt text is short and meaningful — not "image" or a file name, and not a full paragraph.

❌ Before: missing / useless alt text

✅ After: proper alt text

Rules used

1. Informative images get a short description.
2. Decorative images get an empty alt (alt="") so screen readers skip them.
3. Never write "image of..." or the file name — the screen reader already says it is an image.
