Hello, Git!

This is my practice project for the Week 10 Git exercises. I created this folder, turned it into a Git repository, added a style branch, and pushed it to GitHub.

  • E1 — Init: git init, git add ., git commit -m "Initial commit"

Check the history anytime with git log --oneline.
