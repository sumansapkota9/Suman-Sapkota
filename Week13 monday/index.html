Four rules to keep

  1. The input reads from state. The value on screen always comes from state.
  2. Every keystroke writes back to state. onChange keeps the two in step.
  3. The button waits for valid input. A form sends only when every field checks out.
  4. One state per field. Each field owns its value — nothing is read from the page.
